# TOKEN.md: ideas only, not built

Series Zero v1 has **no crypto token**. Scrip (`§`) is an off-chain ledger number with no cash value, no transfers and no market. This file only records ideas for later; none of it is implemented, promised or scheduled.

## Ordered ideas

1. **Off-chain points first.** Keep scrip and season scores as plain database rows for at least several seasons. Learn what players value before anything is made scarce or transferable.
2. **Season-end airdrop (hypothetical).** If a token ever exists, the only distribution considered is a retroactive season-end allocation based on already-recorded, non-purchasable achievements (Demo Day ranks, fund TVPI ranks). No sale, no pre-mine for insiders.
3. **Token only for scarce things.** A token would only represent things that are naturally scarce and cosmetic (title cards, a Demo Day trophy for a given season), never scrip, never outcomes, never odds. Gameplay must stay identical with or without it.
4. **No pay-to-win.** Nothing purchasable may change rolls, marks, ranks or hidden stats.

## Preconditions before any work

- **Legal review** in every target jurisdiction (securities, gambling, consumer protection, sweepstakes, tax) before writing code.
- Clear separation of the simulation (fictional, not investment advice) from anything with market value.
- Age gating, KYC and sanctions questions answered by counsel.
- A written decision that the game is still fun and fair for players who never touch a token.

Until all of the above is done, the answer is: no token.
