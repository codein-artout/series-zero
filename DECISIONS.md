# DECISIONS.md

Ambiguities resolved during the unattended build. Format: date · decision · why. Every choice that changes a number is configurable in `config/game.ts`.

| Date | Decision | Why |
|---|---|---|
| 2026-11-04 | Game config lives at `config/game.ts` (not `src/config/game.config.ts` as GAME.md says). | The build brief names `config/game.ts`; the repo has no `src/` dir. Same zod validation and `GAME_CONFIG_PATH` override apply. |
| 2026-11-04 | Next.js 15.5 (App Router), React 19.2, TypeScript 5.9 strict, Tailwind v4 (CSS-first `@theme`). | Latest stable line that Auth.js v5 beta supports; TS 7 is too new for Next 15 tooling. Tailwind v4 theme tokens are declared in CSS `@theme`, which is the v4 form of "theme extensions". |
| 2026-11-04 | Prisma 7 (`prisma-client` generator, driver adapters). With no `DATABASE_URL` the app uses embedded PGlite through `pglite-prisma-adapter`; with `DATABASE_URL` it uses `@prisma/adapter-pg`. | Zero-setup local runs with the same Postgres dialect as Neon. |
| 2026-11-04 | Migrations are SQL files generated by `prisma migrate diff` and committed under `prisma/migrations/*/migration.sql`. A tiny runner (`lib/db/migrate.ts`) applies them to PGlite; on Neon use `prisma migrate deploy`. | Prisma CLI cannot talk to an in-process PGlite. The SQL files are the same in both paths. |
| 2026-11-04 | Playwright pinned to 1.63.0. | Matches the Chromium build pre-installed in the build machine, so e2e runs offline. |
| 2026-11-04 | Cards are rendered with `next/og` (bundled Satori + resvg) in the Node runtime with self-hosted `@fontsource` WOFF fonts. | No external font or CDN request at runtime. |
| 2026-11-04 | Sector `drift`, `volatility`, `newsSensitivity` defaults (GAME.md gives only pool sizes): drift 0 to 0.0004 per tick, volatility 0.004 to 0.007, sensitivity 0.8 to 1.3. | Keeps pools inside the `[0.5, 2.0]` clamp over a season while still moving week to week. All in `config.sectors`. |
| 2026-11-04 | New companies start with `company.startingCash = §400,000` minted with reason `angel` (cap table 80% founder, 10% angels, 10% pool, as in the TermSheet mockup). | GAME.md lists no mint source for a company's first cash, but burn starts on tick one. The mint is logged like every other source. |
| 2026-11-04 | Unpaid opex becomes company `debt` (a number, not scrip). "Cash below 0" in GAME.md 8.6 means `debt > 0`; new cash pays debt to `BURN` first. | The ledger forbids negative balances; this keeps the invariant exact. |
| 2026-11-04 | Ambition "pivot tolerance" maps to a pivot threshold adjustment (`ambition.pivotThresholdAdj`): bootstrap −0.10, lifestyle 0, moonshot +0.15 until runway < 30 days. "Hire bias" high = +1 hire on a hiring week (`ambition.hireBias`). | GAME.md gives qualitative labels only. |
| 2026-11-04 | RNG domains extended with `stats`, `names`, `odds`, `season`, `crash` (still substreams of the season seed). Beta(2,2) is drawn as the median of three uniforms. | Needed for hidden stat draws, name generation and forward odds without sharing streams. Median-of-3 is exactly Beta(2,2). |
| 2026-11-04 | Persistence model: mutable entities (season, sectors, founders, funds, companies, offers, deals, exit offers, decisions, feuds) keep indexed columns plus the full engine object in a `state` JSON column; logs (ledger entries, marks, posts, pitches, events, ticks, notifications, drafts, demo days) are append-only tables. A tick loads the world, runs pure rules in memory, then saves in one transaction with an optimistic `Season.version` check. | Keeps `lib/rules` pure and the tick deterministic, while the DB stays queryable for screens. JSON round-trips of doubles are exact. |
| 2026-11-04 | `pnpm db:migration <name>` diffs `prisma/migrations/schema.snapshot.prisma` against the schema with `prisma migrate diff` (no DB needed). | Works without a shadow database. |
